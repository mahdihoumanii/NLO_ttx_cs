# cs_ppttb

Clean standalone packaging of the validated Catani-Seymour `pp -> t tbar` NLO code at 8 TeV.

This package contains the local analytic Born, color-correlation, collinear-counterterm, virtual, and integrated-dipole code needed to reproduce the validated scalar 8 TeV baseline without any MATRIX or OpenLoops runtime calls.

Current scope:

- LO is integrated locally.
- CA is integrated locally.
- VA is integrated locally.
- RA is packaged honestly as a validated total artifact.
- A fully local spin-correlated RA runtime is not yet implemented inside this package, so the default run assembles the scalar NLO baseline but does not fabricate a differential NLO histogram.

## Layout

- `include/`, `src/`: production C++ code.
- `apps/cs_ppttb.cpp`: main executable.
- `config/default_8tev.cfg`: baseline run configuration.
- `data/references/`: born phase-space table and reference artifacts copied into the package.
- `validation/`: validated scalar baseline artifacts.
- `results/`: created on execution.

## Build

The package expects LHAPDF to be available. In the existing workflow this comes from the conda environment under `/opt/homebrew/Caskroom/miniconda/base/envs/lhapdf`.

Example build:

```bash
cd cs_ppttb
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DLHAPDF_CONFIG_EXECUTABLE="$CONDA_PREFIX/bin/lhapdf-config"
cmake --build build -j
```

If `LHAPDF_DATA_PATH` is unset, the executable will first try `$CONDA_PREFIX/share/LHAPDF`, then the validated fallback path used in this workspace.

## Run

Baseline package run:

```bash
cd cs_ppttb
./build/bin/cs_ppttb --config config/default_8tev.cfg
```	

Fast smoke test:

```bash
cd cs_ppttb
./build/bin/cs_ppttb --config config/default_8tev.cfg --lo-samples 2000 --ca-samples 2000 --va-samples 2000 --output-dir results/smoke
```

The executable writes the enabled outputs requested in the configuration, for example:

- `results/.../summary.txt`
- `results/.../csv/component_totals.tsv`
- `results/.../csv/mtt_lo.csv`
- `results/.../plots/png/mtt_lo.png`
- `results/.../plots/pdf/mtt_lo.pdf`

If a matching RA differential histogram is provided for an enabled NLO distribution, the package also writes the corresponding `*_ra.csv`, `*_ca.csv`, `*_va.csv`, `*_nlo.csv`, `*_nlo.png`, and `*_nlo.pdf` files.
The default config exposes independent LO/NLO switches for `mtt`, `top_pt`, `tb_pt`, and `ytt`, for example `top_pt_lo = True` or `ytt_nlo = False`.

## Python Comparison Plot

The package also ships a Python plotting utility for MadGraph comparisons:

```bash
cd cs_ppttb
./build/bin/cs_ppttb --config config/mtt_madgraph_reference_8tev.cfg
/opt/homebrew/Caskroom/miniconda/base/envs/lhapdf/bin/python scripts/plot_mtt_madgraph_comparison.py
```

By default it reads:

- `data/references/mg_lo_ppttx_mtt_8tev_mu173.hwu`
- `data/references/mg_nlo_ppttx_mtt_8tev_mu173.hwu`
- `results/mtt_madgraph_reference_8tev/csv/mtt_lo.csv`
- `results/mtt_madgraph_reference_8tev/csv/mtt_nlo.csv`

and writes:

- `results/mtt_madgraph_reference_8tev/plots/python/mtt_lo_vs_madgraph.png`
- `results/mtt_madgraph_reference_8tev/plots/python/mtt_lo_vs_madgraph.pdf`

The script treats the MadGraph `.hwu` bins as integrated `pb/bin` values and converts the local CSV from `fb/GeV` to `pb/bin` before plotting.

The matched-bin config now expects the RA differential input at `validation/local_ra_mtt_8tev_60bins_300_1000_100k.csv`. You can produce it from the repository root with:

```bash
export LHAPDF_DATA_PATH=/opt/homebrew/Caskroom/miniconda/base/envs/lhapdf/share/LHAPDF
export DYLD_LIBRARY_PATH=/opt/homebrew/Caskroom/miniconda/base/envs/lhapdf/lib${DYLD_LIBRARY_PATH:+:$DYLD_LIBRARY_PATH}
./build/run_ra_integral_independent --samples 100000 \
	--output validation/local_ra_integral_all_channels_independent_hist_100k.txt \
	--convergence-output validation/ra_integral_all_channels_independent_hist_100k_convergence.txt \
	--histogram-output cs_ppttb/validation/local_ra_mtt_8tev_60bins_300_1000_100k.csv \
	--sqrt-s-gev 8000 --mtt-bins 60 --mtt-min 300 --mtt-max 1000
```

For 13 TeV total-rate checks, use [config/default_13tev.cfg](config/default_13tev.cfg). RA artifacts generated by the independent driver now include `sqrt_s_gev`, `mt_gev`, `muF_gev`, and `muR_gev` metadata; the package refuses to use a metadata-rich artifact whose setup does not match the run config, and treats metadata-free legacy artifacts as 8 TeV only.

For a closer visual match to the MadGraph reference binning, the package includes [config/mtt_madgraph_reference_8tev.cfg](config/mtt_madgraph_reference_8tev.cfg). Running the executable with that config regenerates the local histograms on the same 60-bin `300..1000 GeV` grid used by the reference `.hwu` files.

## Config keys

- `sqrt_s_gev`, `mt_gev`, `muF_gev`, `muR_gev`
- `pdf_set`, `pdf_member`
- `lo_samples`, `ca_samples`, `va_samples`, `seed`
- `ra_mode`, `ra_artifact`, `ra_histogram_csv`
- `born_phase_space`
- `output_dir`
- `mtt_bins`, `mtt_min_gev`, `mtt_max_gev`
- `top_pt_bins`, `top_pt_min_gev`, `top_pt_max_gev`
- `tb_pt_bins`, `tb_pt_min_gev`, `tb_pt_max_gev`
- `ytt_bins`, `ytt_min`, `ytt_max`
- `reference_lo_csv`, `reference_nlo_csv`
- `write_csv`, `write_plots`
- `mtt_lo`, `mtt_nlo`, `top_pt_lo`, `top_pt_nlo`, `tb_pt_lo`, `tb_pt_nlo`, `ytt_lo`, `ytt_nlo`
- `mtt_ra_histogram_csv`, `top_pt_ra_histogram_csv`, `tb_pt_ra_histogram_csv`, `ytt_ra_histogram_csv`

Reference overlays are optional. The expected CSV format is:

```text
bin_low_gev,bin_high_gev,value,error
```

## Validated scalar baseline

Packaged target baseline:

- `LO = 147.766443 +/- 0.390296 pb`
- `RA = -5.272178 +/- 0.124132 pb`
- `CA = 88.683327 +/- 0.363896 pb`
- `VA = -12.987509 +/- 0.026842 pb`
- `NLO = 218.190083 +/- 0.548526 pb`

See `validation/validated_baseline_8tev.txt` for the frozen reference note.
